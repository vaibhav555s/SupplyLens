TABLE 26 ---
Decision | Choice Made | Why
Edge confidence model | VERIFIED vs INFERRED (binary, not a score) | Binary is clearer for the user and simpler to maintain; aligns with data source types
Graph persistence | Neo4j graph database, not relational | Graph queries (find all paths, N-hop traversal) are natural in Cypher; terrible in SQL
BOM filter | HS sub-tree + LLM binary check (not LLM alone) | Sub-tree is fast, deterministic, cheap; LLM only runs when sub-tree is ambiguous
Tier-2+ company resolution | Mirror trick before country-level fallback | Maximises verified edges; country nodes are a fallback of last resort, not the default
Dark nodes (China domestic) | Grey node labelled 'Unknown domestic supplier' | Honest about data gaps; more useful than hiding the node or hallucinating a name
Stop condition | HS Chapter 01–27 OR depth=6 | Raw commodities have no upstream; depth cap prevents infinite loops on circular trade
Frontend graph library | Cytoscape.js | Purpose-built for network graphs; handles large node counts; good React integration
Disruption simulation | Pure graph traversal on existing data (no re-fetch) | Graph already has the data; disruption is just re-colouring — instant, demo-friendly
BOM filter transparency | Pruned nodes panel in UI (visible, auditable) | Differentiates from teams who silently filter; builds judge confidence

TABLE 27 ---
Limitation | Scope | Mitigation
US sea shipments only at Tier-0/1 | ImportYeti covers US sea freight only — air and overland excluded | Layer in Zauba for Indian legs; use mirror trick for other open-data countries
China domestic transactions invisible | Intra-China trade never crosses a publicly recorded border | Show as grey 'unknown domestic supplier' node; LLM inference can suggest known names
UN Comtrade 500 calls/day limit | Deep traversals on large companies may hit daily limit | Redis cache all Comtrade responses; batch calls; queue non-urgent traversals
ImportYeti data latency | ImportYeti data lags US CBP by 3–4 months | Label data with date range; note 'most recent records: MM/YYYY' in UI
LLM-inferred edges not ground truth | LLM may hallucinate supplier names for unknown companies | All LLM edges marked INFERRED with low-confidence badge; never shown as verified
~23% of nodes will be country-level | Based on Tesla ground-truth analysis, ~4 of 17 nodes are China-domestic dark spots | Show as grey nodes with HS code + country — honest and still useful for risk assessment
